# goit-js-hw-05

Домашнє завдання №5 з курсу JavaScript (перебираючі методи масивів: `map`,
`filter`, `toSorted` та ланцюжки методів).

## Структура проєкту

- `js/task-1.js` — Задача 1. Імена користувачів (`getUserNames`)
- `js/task-2.js` — Задача 2. Користувачі з другом (`getUsersWithFriend`)
- `js/task-3.js` — Задача 3. Сортування за кількістю друзів
  (`sortByDescendingFriendCount`)
- `js/task-4.js` — Задача 4. Загальний баланс (`getTotalBalanceByGender`)
